# 夜班 · 门房 / NIGHT DOORMAN

一个**监控视角的恐怖游戏**。你是温岸公寓的夜班门房，22:00 到 05:30 坐在监控台前。
每一个来访的人都要进门——**看证件、查登记册、看本人**，三样对得上才开门。

## 怎么玩

**直接双击 `index.html`。** 不需要服务器、不需要安装任何东西。

### 键盘

| 键 | 作用 |
|---|---|
| `1` `2` `3` `4` | 切换监控通道（大门外 / 一层门厅 / 楼梯间 / 楼层走廊） |
| `Enter` | 放行 |
| `Backspace` | 拒收 |
| `F` | 手电（照门外那位的脸） |
| `R` | 翻开守则手册 |
| `M` | 静音 |

### 判定流程

1. 门口有人按铃 → 他会把**通行证**举到摄像头前，右栏出现证件照与信息。
2. 对着右栏的**楼梯登记册**核对：这个房号登记的是谁？有效期到什么时候？备注栏有没有红字？
3. 再抬头看门外**这个人本人**——证件照上有的东西，他身上也该有；证件照上没有的东西，他身上不该有。
4. `Enter` 放行 / `Backspace` 拒收。

**证件照画的永远是他"本该长的样子"，门口站的是他"现在的样子"。**
两者对不上，就别开门。

### 守则

守则由 7 条逐夜增加（第 7 夜起全开），随时按 `R` 翻看：

1. 证件必须在有效期内
2. 证件姓名必须与该房号登记住户一致
3. 房号栏不得有涂改痕迹
4. 同一房号、同一姓名，当夜只放行一次
5. 物业封存的房号不得放入外人（住户本人除外）
6. 影子方向不对、或者根本没有影子 → 不是人
7. 身上出现不该有的东西 → 一律拒收

### 会输的地方

- **放行了不该放的人** → 立刻跳脸，夜班结束
- **错拒住户累计 3 次** → 被物业调离
- **让人在门外站满 40 秒** → 算一次失误

整夜零失误才能进下一夜。

## 文件

| 文件 | 内容 |
|---|---|
| `index.html` | 三栏监控台布局 |
| `style.css` | 暗金属 + CRT 绿主题、扫描线、暗角、噪点 |
| `js/audio.js` | `SFX`——WebAudio 全程序化音效（无音频文件） |
| `js/visitor.js` | `Visitors`——住户生成、访客生成、突变与诱饵表 |
| `js/camera.js` | `Cameras`——四个通道的画面绘制与人物质感 |
| `js/registry.js` | `Registry`——登记册与七条守则的判定核心 |
| `js/game.js` | 主循环、状态机、界面接线 |
| `DESIGN.md` | 设计稿（含"走过的弯路"） |
| `_test/sim.js` | 无头不变量模拟，用来验证规则公平性 |
| `_shots/` | 开发期的截图（可以整个删掉） |

> `_test/sim.js` 是开发工具，不影响游戏运行：
> `node _test/sim.js` 会逐夜生成访客并核对"真住户不得被错拒 / 假货必须有破绽 / 二次到访必须排在后面"。

## 调试参数

正常游玩不用管这些。带参数时：

```
index.html?auto=1&night=5&seed=7&cam=lobby&mute=1
```

`auto` 跳过开场 · `night=N` 跳到第 N 夜 · `seed=N` 固定随机种子 · `cam=` 直接切通道 ·
`mute=1` 静音 · `norules=1` 关掉守则弹窗 · `probe=1` 状态浮层 ·
`pose=wait:0` 摆姿势 · `mut=eyes-extra,hair-up` 强行叠加身体异常 ·
`flash=1` 开手电 · `decide=right|wrong` 直接判一次 · `finish=0|2` 直接看交班画面

另有两份仅供调试的全局对象：`window.__dbg`（`state/errs/spawnNow/decide/switchCam/release/deny/set`）
与 `window.__errs`（页面异常收集）。

## 在线玩（GitHub Pages）

本作是纯静态页面，推到 GitHub 之后可以直接开 Pages 玩：

**Settings → Pages → Source: Deploy from a branch → Branch: `main` / `/ (root)` → Save**

几分钟后地址是 `https://<你的用户名>.github.io/doorman/`，点开就能玩。
（仓库必须是**公开**的，Pages 在私有仓库上需要付费版 GitHub。）
