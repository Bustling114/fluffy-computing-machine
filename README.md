# 夜班 · 门房 / NIGHT DOORMAN

一个**监控视角的恐怖游戏**。你是温岸公寓的夜班门房，22:00 到 05:30 坐在监控台前。
每一个来访的人都要进门——**看证件、查登记册、看本人**，三样对得上才开门。

## 怎么玩

**直接双击 `index.html`。** 不需要服务器、不需要安装任何东西。

### 键盘

| 键 | 作用 |
|---|---|
| `1` `2` `3` `4` | 切换监控通道（大门外 / 一层门厅 / 楼梯间 / 楼层走廊） |
| `Enter` | 放行 |
| `Backspace` | 拒收 |
| `F` | 手电（照门外那位的脸） |
| `R` | 翻开守则手册 |
| `M` | 静音 |
| `F1` 或 `` ` `` | 打开／收起调试面板（见下） |

### 判定流程

1. 门口有人按铃 → 他会把**通行证**举到摄像头前，右栏出现证件照与信息。
2. 对着右栏的**楼梯登记册**核对：这个房号登记的是谁？有效期到什么时候？备注栏有没有红字？
3. 再抬头看门外**这个人本人**——证件照上有的东西，他身上也该有；证件照上没有的东西，他身上不该有。
4. `Enter` 放行 / `Backspace` 拒收。

**证件照画的永远是他"本该长的样子"，门口站的是他"现在的样子"。**
两者对不上，就别开门。

### 守则

守则由 7 条逐夜增加（第 7 夜起全开），随时按 `R` 翻看：

1. 证件必须在有效期内
2. 证件姓名必须与该房号登记住户一致
3. 房号栏不得有涂改痕迹
4. 同一房号、同一姓名，当夜只放行一次
5. 物业封存的房号不得放入外人（住户本人除外）
6. 影子方向不对、或者根本没有影子 → 不是人
7. 身上出现不该有的东西 → 一律拒收

### 会输的地方

- **放行了不该放的人** → 立刻跳脸，夜班结束
- **错拒住户累计 3 次** → 被物业调离
- **让人在门外站满 40 秒** → 算一次失误

整夜零失误才能进下一夜。

## 路上的细节（不是规则，但值得盯一眼）

放行之后，那个人不会就这么消失——他会走进门厅、等电梯、上到你正在看的那一层，
再从电梯里出来走到自己房号门口。**四个通道串成了一条完整的动线**，你可以一路跟到底。

守夜的时候，楼里还会自己发生一些事：走廊的灯闪一下、某扇门开了一条缝、楼梯间
有脚步声、对讲机响了一声、对面楼有一扇窗的灯灭了、门厅的电梯自己下来了一趟……

**这些全都不是判定依据。** 出现的身影一律是错过的、已经进去的、或者根本不是人的东西。
它们只负责让你在核对登记册的间隙里抬头看一眼——然后不确定自己刚才看见了什么。
哪个通道有新动静，左侧那个通道按钮上会亮一个红点。

| 文件 | 内容 |
|---|---|
| `index.html` | 三栏监控台布局 |
| `style.css` | 暗金属 + CRT 绿主题、扫描线、暗角、噪点 |
| `js/audio.js` | `SFX`——WebAudio 全程序化音效（无音频文件） |
| `js/visitor.js` | `Visitors`——住户生成、访客生成、突变与诱饵表 |
| `js/camera.js` | `Cameras`——四个通道的画面绘制与人物质感 |
| `js/registry.js` | `Registry`——登记册与七条守则的判定核心 |
| `js/events.js` | `Events`——设施内的 15 条氛围事件（**绝不参与判定**） |
| `js/game.js` | 主循环、状态机、界面接线、调试面板 |
| `DESIGN.md` | 设计稿（含"走过的弯路"） |
| `_test/sim.js` | 无头不变量模拟，用来验证规则公平性 |
| `_test/events.js` | 随机事件探针（可达性、回收、判定不变性） |
| `_test/faces.js` | 外观系统探针（同夜同房号必须同一张脸） |
| `_test/canvas.js` | 假 Canvas2D，用数字验证画面级事件真的画上去了 |
| `_test/canvastest.js` | 上面那个假画布的自检 |
| `_test/syntax.js` | 六个 js 文件的语法检查 + 装载 + 事件冒烟 |

> `_test/` 里全是开发工具，不影响游戏运行。跑法都一样：`node _test/xxx.js`。
> 四个探针全绿代表"规则公平、事件不干扰判定、外观自洽、画面级事件确实落在画布上"。

## 调试面板

按 `F1` 或 `` ` `` 打开（也可以 `?debug=1` 让它一开局就展开）。里面是：

- **本夜**：`1`–`12` 直接跳夜、`跳到交班`、`离开`
- **时间**：`0.5×` / `1×` / `3×` / `8×` / `25×` 倍速，`暂停 / 继续`
- **访客**：`立刻叫一个`、`放行`、`拒收`、`自动判定 ×10`
- **揭示真身**：把当前这位的类型、真身／披的人皮、本夜生效的规则、判定结果，
  以及他身上到底带着哪些突变／诱饵／破绽全部抖出来
- **概率（本局有效）**：假货率、双层突变率、诱饵率，拖动即时生效
- **设施内随机事件**：开／关、`立刻来一个`、下一个还有几秒、生效中几条、间隔秒数
- **画面**：扫描线、暗角、噪点的强度

`揭示真身` 是给你确认"这一位本来该怎么判"的；关掉面板就是正常游玩。

## 调试参数

正常游玩不用管这些。带参数时：

```
index.html?auto=1&night=5&seed=7&cam=lobby&mute=1
```

`auto` 跳过开场 · `night=N` 跳到第 N 夜 · `seed=N` 固定随机种子 · `cam=` 直接切通道 ·
`mute=1` 静音 · `norules=1` 关掉守则弹窗 · `probe=1` 状态浮层 · `debug=1` 开局展开调试面板 ·
`pose=wait:0` 摆姿势 · `mut=eyes-extra,hair-up` 强行叠加身体异常 ·
`face=ponytail,beard` 强行改当前这位的发型／附加特征 ·
`vfx=flicker,ajar,exitPulse,elevatorDoor,intercom,windowOut,tint-red` 强行开画面级事件 ·
`flash=1` 开手电 · `decide=right|wrong` 直接判一次 · `finish=0|2` 直接看交班画面 ·
`warp=25` 整局快进 · `errs=1` 右下角常驻一个运行时异常计数

另有两份仅供调试的全局对象：`window.__dbg`（`state/errs/spawnNow/decide/switchCam/release/deny/set`）
与 `window.__errs`（页面异常收集）。
